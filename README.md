# Me · 我的日常

记录想法、安排日程和管理待办，适配电脑与手机。正式域名：[me.joybeat.cn](https://me.joybeat.cn)。

**当前版本 3.1.1，已于 2026-09-07 发布。** 无需客户端证书，支持邮箱验证公开注册、账号独立数据、Qwen-Flash 整理、语音输入和 PushPlus 微信回执。百炼密钥已启用，文字整理与语音转写均通过真实调用验证。实际配置与验收依据见 [部署记录](deploy/DEPLOYED.md)。

## 组织协作

个人空间顶部可切换、创建或加入组织；手机也有同一入口。组织以验证邮箱邀请成员，链接有效 7 天，需本人主动接收。网站账号角色与组织角色分别管理。

- 管理者在组织中点“新建”，填写内容并确认负责人、范围、期限与验收要求；员工可直接登记自己的工作。
- 工作台、列表、任务看板、四象限、周/月甘特图使用同一任务。个人首页的“我的一天”汇总个人事项与组织的逾期、接收、验收和今日计划，标明来源。任务可按人、项目、部门、状态、来源筛选；支持有权限的批量改派、取消、归档。
- 草稿仅作者可见。正式任务默认向参与人和有权管理者开放；普通成员通过变更申请调整期限或负责人。需要验收时，提交后由另一位有管理权限的成员通过或退回。
- 私人记录中的“只读分享”仅公开预览快照，可手动更新或撤回；“生成组织任务”生成独立组织任务。私人原文、关联历史和后续修改不自动公开。
- 组织可建立简单部门与项目、任命范围负责人。停用成员立即撤销组织访问，工作保留在待交接列表。所有者转让需接收人确认。
- 组织 AI、云端语音、PushPlus 外发默认关闭，组织设置可分别开启。AI 只整理选定草稿，人工确认后发布；费用按组织归属计入同一平台总额度。
- 微信需要组织允许外发、成员连接自己的 PushPlus 并开启本组织通知。默认仅发通用提示与登录链接；任务正文不外发。投递回执、知晓、接收、提交和验收分别记录；提供静音、免打扰、每日摘要与稍后提醒。
- 组织内容仅在线使用，不进入个人离线数据库。导出组织数据需独立管理权限，只读分享不进入批量导出。完整服务器备份包括组织、成员、任务、讨论、审计、用量和通知记录。

首版暂不包含多级部门、附件、依赖排程、企业微信应用或自动绩效评分。详细规则见 [组织协作方案](ORGANIZATION-PLAN.md)。

## 3.1 使用体验与重复计划

- 组织新建与有权执行/编辑的任务内容自动保存到作者自己的“草稿与模板”。刷新后从草稿箱恢复；短暂连接失败保留当前输入并重试，权限失效则清除当前组织视图。未保存成功的内容不能保证在强制关闭后恢复。
- AI 整理会保留手填标题、时间、优先级等字段，并展示差异供选择；拆分后的第一项保留手填字段，其余逐项确认。
- 成员选择可以搜索并勾选，分配表单按项目/部门权限提供候选。员工默认关注本人任务，管理者保留交接、阻塞和验收指标。
- 在新建页面保存常用模板，随后进入“草稿与模板”新建或建立重复计划。重复计划支持每天、周一至五、每周和每月；每次创建独立实例，可暂停或结束。权限失效时暂停，停机跳过旧实例；工作日不自动处理节假日调休。
- 当前模板与重复计划仅在组织中提供且仅创建者可管理；修改规则内容需新建计划并结束旧计划。组织通知会明确显示未开启、未绑定、静音、免打扰或等待汇总等原因。

本轮验证、仍未完成项和 AI 下一步见 [改进路线](PRODUCTIVITY-ROADMAP.md)。

## 账号版使用方式

1. 注册时验证邮箱、设置至少 10 个字符的密码，之后用邮箱和密码登录。
2. 每个账号独立保存记录、草稿、待办、日程、通知连接和登录设备。主账号 `1210604006@cnu.edu.cn` 验证注册后继承首版全部记录。
3. 在“账号与设置”关注并连接 PushPlus，发送测试并在微信确认收到。编辑内容时可选择“保存并推送微信”，或设置提醒时间并勾选微信提醒。
4. 可以退出其他设备、修改密码、通过邮箱验证码重设密码，以及导入、导出自己的数据。

PushPlus 只接收用户主动推送或勾选提醒的内容；连接前需要用户同意。通知令牌加密保存，正文最多发送前 2,000 字符，附带需要登录的原文链接。平台返回成功只代表受理，界面单独显示回执状态。账号受限、令牌无效或需要实名认证时暂停连接；发送结果不确定时不盲目重发。额度及实名认证要求见 [PushPlus 官方说明](https://www.pushplus.plus/doc/guide/code.html)。

已经登录且当前标签页保留有效离线状态时，断网后可继续记录；离线状态最长保留 12 小时，联网且页面运行时补传。不要在待上传期间清除网站数据。跨设备同时编辑出现冲突时选择版本或保留两份。退出登录会清除当前账号在本机的副本和草稿，待上传内容需要先同步；撤销远程登录无法擦除已下载的离线内容。

## 首页展板

顶部记录条默认收起，点击后输入，保存后自动收起。搜索默认只有图标，点击展开，关闭时清除查找条件。

- 四象限展示未完成的待办和日程。电脑拖动卡片，手机长按左侧拖动柄后移动；也可以点击拖动柄选择目标象限。已划分象限的任务和日程仍可在编辑窗口重新调整重要度。
- 任务看板包含待开始、进行中、已完成。拖入已完成会完成待办，拖出会重新打开；勾选完成时卡片也随之移动。
- 甘特图显示接下来 7 天，跨出范围的安排会裁切，范围外的安排不显示；未安排日期的待办另列。手机可在图内横向滚动。
- 象限和任务进度随账号同步，选中的视图保存在当前浏览器。旧版手动本机分组会在该浏览器打开时迁移。缺少重要性依据的事项放入“待分配”，安排了日期不会自动变成“进行中”。

## AI 整理与回执

- 记录入口提供默认、想法、待办、日程。默认由 AI 判断类别，手动类别优先；所有新记录先保存，后台再整理。关闭 AI、离线、额度不足或失败时，原文仍可保存。
- Qwen-Flash 使用阿里云百炼北京兼容接口、非思考模式和 JSON 输出。服务端验证结构和原文依据，保留原文、标题、摘要、标签和日期；明确的独立事项可拆分。手动填写的时间和标题优先保留。
- 相对日期以记录时刻及北京时间解释。模糊时刻待补，不默认添加一小时结束时间。重要性缺少依据时不强行归入某个象限。明确要求提醒且有准确时间时才生成提醒。
- 整理完成后可查看原文、重新整理或撤销。AI 等待期间的手动修改不会被覆盖；整理后的任一拆分项已修改时，整组撤销会拒绝，原文仍可查看。
- 主账号依照本次接入请求默认开启 AI；其他账号需要在“账号与设置 → AI 整理”同意发送当前内容给百炼。自动使用微信提醒另有开关，需要已有 PushPlus 连接。
- 新微信通知中的“查看并处理”打开需要登录的回执页。“已知晓”只记回执；“已完成”完成待办；“稍后提醒”支持 15、30、60 分钟。GET 链接不会改变事项，操作需当前账号会话、CSRF 和版本校验；重复点击不会反复延后。
- 平台回执单独显示。5 分钟未返回则标记“投递结果未确认”，迟到的有效回调仍可更新；平台成功不代表本人已读。

管理员通过本机 `scripts/ai-setup.mjs` 的安全表单保存密钥到受保护文件，再配置服务器 `/data/joybeat-me/config/ai.json`（UID 1000、权限 600）。生产设置 `AI_CONFIG_FILE=/config/ai.json`，配置不进入前端或日志。参考 `deploy/ai.example.json`；修改配置后重启 Me。

初始每账号每日 100 次、全站每日 2,000 次、每月预算 20 元。以北京时间计日/月；按短上下文输入 ¥0.15/百万 token、输出 ¥1.5/百万 token 估算，发送前预留，成功后以实际 token 数结算；结果不确定时保留预留额。应用预算只覆盖此应用调用，实际账单和价格以百炼为准。单次 AI 内容限 8,000 字，普通保存仍支持 50,000 字。

## 语音输入

快速记录旁的麦克风按钮打开语音输入，阅读录音说明后点击“同意并开始录音”。首次使用需允许网站访问麦克风；说完点击“停止并转文字”。结果追加到现有草稿，确认后点击“记下来”，使用已选择的默认/想法/待办/日程类别继续整理。

- 支持提供 MediaRecorder 和 Web Audio 的现代 Chrome、Edge、Safari 等浏览器；手机和电脑均使用同一入口。需要 HTTPS 和网络，录音保持页面在前台；切到后台会停止麦克风，回到页面后可提交已录片段。
- 单次最多两分钟。浏览器把录音转换成 16 kHz 单声道 WAV，服务端检查真实格式、长度、静音、账号和同意状态后发送给百炼 `qwen3-asr-flash`。密钥仅保存在服务器。
- Me 不持久保存原始录音。转写文本在当前账号的临时结果表保留约十分钟，以便网络失败后取回结果；随后清空文本，记录标记保留一天。未点击“记下来”不会自动创建事项。取消/关闭页面会释放麦克风，页面内尚未转写成功的录音不会跨刷新保存。
- 网络重试优先查询同一次请求的结果，避免重复调用。服务商已经明确失败时，点击重试才发起新调用。录音成功后的修改或追加都保留已有草稿。
- 默认每账号每天 20 分钟、100 次上限，全站每天 300 分钟；文字整理与语音共用原有每月 20 元应用预算。按北京语音价格每秒 0.00022 元向上取整预留；失败或不确定的调用仍保留预留金额。真实账单及其他应用调用以百炼为准。

接口与价格：[百炼 Qwen-ASR 文档](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)、[Qwen3-ASR-Flash 模型价格](https://help.aliyun.com/zh/model-studio/qwen3-asr-flash)。

## 开发

需要 Node.js 24.15 以上，生产镜像为 Node.js 24.19.0。

```sh
npm ci
npm test
npm run build
npm run dev
```

本地开发绑定 `127.0.0.1`，独立数据位于 `.local/dev`。首次自动创建 `.local/dev/account.json`，默认不配置发信。可用 `ACCOUNT_CONFIG_FILE` 指定受保护的运行配置；格式见 [配置示例](deploy/account.example.json)。禁止把真实密码、SMTP 授权码或通知令牌放入源码。

React + Vite；Express + SQLite；Coolify 管理 Docker Compose，Traefik 提供 HTTPS。生产使用 `AUTH_MODE=account` 与只读 `ACCOUNT_CONFIG_FILE=/config/account.json`。服务不发布宿主机端口。
